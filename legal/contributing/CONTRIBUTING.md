# Contributing to Pill Engine

Thanks for wanting to help build Pill Engine! Bug reports, documentation,
examples, tests and code are all welcome.

Everything you need to get started, from the workflow and coding standards
to the rules for third-party code, is in the
[contributing guide](https://docs.pillengine.org/guide/other/contributing/getting-started).

A few things to know before your first pull request:

- **Sign the CLA once.** When you open your first pull request, you'll be
  asked to accept the [Individual CLA](CLA.md). If your employer, client or
  university may own your work, they also sign the
  [Corporate CLA](CCLA.md) or give you written permission to contribute.
  You never need to sign anything just to use Pill Engine.
- **Only share what you're free to publish.** Please don't submit code
  covered by a console maker's confidentiality terms, or a security fix
  that hasn't been disclosed yet.
- **Found a security issue?** Please report it privately to
  contact@pillengine.org instead of opening a public issue.

Not sure about something? Just ask. We're happy to help.
